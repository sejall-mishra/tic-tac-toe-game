# Tic-Tac-Toe

A console Tic-Tac-Toe game in Python where you play against the computer.

## Features

- Easy mode: the computer plays random moves
- Unbeatable mode: the computer uses the Minimax algorithm
- Input validation, win and draw detection, and play again

## How to run

1. Install Python 3
2. Run: `python tictactoe.py`

## What I learned

- Lists, loops and functions
- The Minimax algorithm and recursion
- Using Git and GitHub
